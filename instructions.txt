This is how to use a teleOp:

Since the robot is simple right now (and the other file isn't quite configured) use 'workableTeleOp'.

It is super simple, but should be able to drive around with the joysticks. It should be that left joystick is direction to move in, while right joystick is heading.

If it doesn't work, you can find code online, or analyze the what the wheels are doing when you go forward and figure out what code changes would fix it. Before anything, 
try reversing the direction of the motors, or flipping the sign of the controller values (they're called like gamepad1_left_stick_x and gamepad1_left_stick_y or something).
You can also change the formulas used for determining power. 

Part of the code is a comment of reversing certain motors. To unreverse or reverse a motor, simply comment it out or remove the two slashes that make it a comment. 

Also make sure that the strings hardwareMap.get([string here]) are the same as what the driver station says. Additionally, make sure the driver station's names are correctly assigned to the physical motors.

Make sure that your driver station is using gamepad_1.
